# CSV回帰分析・予測アプリ

StreamlitでCSVを読み込み、回帰分析と予測を行う小さなデモアプリです。線形回帰・サポートベクター回帰・ランダムフォレストを同じデータで比較し、評価スコアの高いモデルで目的変数が空欄の行を予測します。

## 主な機能

- CSVのプレビューと数値項目の相関確認
- 3種類の回帰モデルの学習とホールドアウトデータでのスコア比較
- 目的変数が空欄の行の予測と、結果CSVのダウンロード

## 必要なもの

- Python 3
- pip

## 起動方法

リポジトリのルートで仮想環境を作成し、依存パッケージをインストールします。

```bash
python -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
streamlit run 1-3.py
```

Windowsでは仮想環境を `.venv\\Scripts\\Activate.ps1` で有効にしてください。

## CSVの形式

アプリはShift-JISとしてCSVを読み込みます。列は次の順に並べます。

1. 予測したい値（目的変数）
2. 予測に使う数値項目（説明変数）

学習用の行には値を入れ、予測用の行では1列目だけを空欄にします。画面でデータを確認し、「相関関係を確認」または「予測を開始」を選びます。予測結果は画面で確認でき、CSVとしてダウンロードできます。

## モデルと評価

アプリ内で `LinearRegression`、`SVR`、`RandomForestRegressor` を学習します。データを学習用とテスト用に分割し、テスト用データで各モデルのスコアを比較してから予測に使うモデルを選びます。表示スコアは入力データに依存し、予測精度を保証するものではありません。
